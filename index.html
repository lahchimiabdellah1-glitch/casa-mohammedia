🔍 Comment vérifier un code Cash Plus ?
1. Ouvre ton appli Cash Plus → Historique / Transactions
2. Cherche le code que le pro a entré
3. Vérifie : Montant = 99 DH ? Date = aujourd'hui / récente ? Nom de l'envoyeur = Nom du pro ?
4. Si montant ≠ 99 DH, ou date vieille, ou nom différent → c'est un code pour un autre service ou périmé / faux → clique sur Refuser / Supprimer.
